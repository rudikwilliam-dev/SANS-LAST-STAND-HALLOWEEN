# SANS: LAST STAND — Halloween Edition

Разработчик: EternalMorte · Telegram: https://t.me/EternalMorte

## Запуск на компьютере
1. Открой `index.html` в современном браузере.
2. Управление: WASD/стрелки — движение, Shift — рывок, P/Esc — пауза, Enter — старт.

## Публикация на GitHub Pages
1. Создай Public-репозиторий на https://github.com/new
2. Загрузи `index.html` в корень ветки `main`.
3. Открой Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. После публикации открой `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Рекорды
ТОП-5 хранится локально в браузере на этом устройстве. Общего онлайн-рейтинга нет. Онлайн-дуэли и счётчик игроков удалены; игра не показывает фальшивые онлайн-данные.
