# SANS: ETERNAL NIGHT — Halloween Edition
**Developer: EternalMorte**

A self-contained browser game. No build tools or external assets required.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload `index.html`, `README.md`, and `.nojekyll` to the root of your repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
4. Wait for deployment and open the URL shown in the Pages section.

## Controls
- WASD / Arrow keys: move
- Space: jump
- Shift: dash / brief invulnerability
- X: fire at the boss
- P / Esc: pause
- Touch controls are shown on mobile screens.

## Notes
- Local top five is stored in this browser using localStorage.
- No online player count or online duels are simulated.
- The game is a fan-made homage; it is not an official Undertale product.
